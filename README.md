# class-command

a small python terminal application for keeping track of school timetables, class countdowns, and breaks.

built in november 2026.

## features

- daily and weekly timetables
- live class countdowns
- upcoming class notifications
- subject and classroom lookup
- automatic school-day switching
- interactive countdown timer
- full-screen terminal clock
- dynamic caelestia color integration
- kitty and foot support

## commands

| command | description |
|---|---|
| `class` | live timetable |
| `class week` | weekly schedule |
| `class now` | current class |
| `class next` | upcoming class |
| `class left` | remaining classes |
| `class free` | breaks and free periods |
| `class find <subject>` | find a subject |
| `class teachers` | teacher directory |
| `class pin` | separate timetable window |
| `class clock` | full-screen clock |
| `class timer` | interactive countdown timer |
